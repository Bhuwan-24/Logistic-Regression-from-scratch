# Logistic Regression From Scratch

This repository contains multiple implementations of **Logistic Regression from scratch using NumPy**.  
The project demonstrates different Gradient Descent optimization techniques used for binary classification problems in machine learning.



##  Implemented Models

- `Logistic_Regression(BGD).ipynb`
- `Logistic_Regression(Mini-BGD).ipynb`
- `Logistic_Regression(SGD).ipynb`



##  Topics Covered

- Logistic Regression
- Binary Classification
- Sigmoid Activation Function
- Batch Gradient Descent (BGD)
- Mini-Batch Gradient Descent
- Stochastic Gradient Descent (SGD)
- Cost Function Optimization
- Weights & Bias Updates
- Model Training From Scratch



##  Technologies Used

- Python
- NumPy
- Matplotlib
- Jupyter Notebook



##  Goal of This Repository

The main goal of this repository is to understand how Logistic Regression works internally without relying on machine learning libraries like Scikit-learn.

This project focuses on:
- Mathematical intuition behind classification
- Optimization techniques
- Gradient Descent algorithms
- Building ML models completely from scratch
